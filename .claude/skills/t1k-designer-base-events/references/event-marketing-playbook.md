# Event Marketing Playbook

## Press Cycle (Major Events Only)

### Timeline
| T-offset | Action |
|----------|--------|
| T-7 days | Press pitch sent with embargo date + asset pack |
| T-3 days | Influencer early access opens + embargo assets delivered |
| T-1 day | App store screenshots and metadata updated |
| T-0 | Embargo lifts: push notification + social post (all channels) |
| T+72h | Follow-up to press with data note: DAU spike %, ARPDAU lift % |

### Press Pitch Template
```
Subject: [Game] [Event Name] — Embargo [Date/Time]

Hi [editor name],

[Game Name] is launching [Event Name] on [date].

What's new:
• [Unique mechanic in 1 line — the most TikTok-able/photographable thing]
• [Exclusive cosmetic — describe the visual hook]
• [Scale hook — "partnering with [IP]" OR "our biggest content drop this year"]

Event runs [start] – [end]. Assets at [link]. Build available for review on request.

Happy to coordinate: [your name] | [your email]
```

### Asset Pack Contents
- Key art: 3840×2160 (desktop) + 1080×1920 (mobile portrait)
- Event logo / title treatment: transparent PNG
- Gameplay screenshot: 3 minimum showing event mechanic
- Exclusive cosmetic showcases: render + in-game screenshot
- Event trailer: 60-second max (YouTube link preferred)

## Store Screenshot Strategy

### Per-Event Screenshot Requirements

| Screenshot | Content | Timing |
|-----------|---------|--------|
| Screenshot 1 | Event key art + title (hero image) | Update 24h before launch |
| Screenshot 2 | Event exclusive cosmetic showcase | Same |
| Screenshot 3 | Event gameplay / mechanic preview | Same |
| Screenshot 4-6 | Keep existing evergreen | No change |

### Apple App Store Submission Notes
- Screenshot review takes 24-48h — submit 2 days before event launch
- "What's New" release notes must mention the event by name (search indexing)
- Request in-app events slot (Apple In-App Events feature — free editorial-adjacent placement)

### Google Play Notes
- "What's New" section update = same-day (no review needed)
- Feature graphic (1024×500) should match event key art if submitted for featuring
- Promotional content submissions via Play Console → Store Presence → Promotional Content

## Influencer Brief Template

```
INFLUENCER BRIEF — [Event Name]
================================
Game: [Name]
Event: [Event Name]
Early access: [Date/Time] to [Date/Time] (3 days before public launch)
Embargo: Do not post before [Date/Time]

CONTENT DIRECTIVE
-----------------
Angle: [Single hook — e.g., "first look at the Phantom Eclipse exclusive skin reveal"]
Tone: [e.g., excited discovery / competitive / cozy]
Length: 30-90 seconds for Reels/TikTok; up to 10 min for YouTube

MUST INCLUDE
------------
- Event name spoken or shown in first 3 seconds
- Link to game in bio during event window
- Mention event end date (urgency)

ASSET PACK
----------
[Drive link]
- Key art (1:1, 9:16, 16:9)
- Event logo PNG
- Talking points PDF (3 bullets)

DELIVERABLE MINIMUM
-------------------
1× TikTok/Reel/YouTube Short
Optional: 1× Community post (tweet, Instagram static)

COMPENSATION
------------
[Early access + in-game exclusive item] OR [Flat fee: $X]
```

```
Title: [Event Name] is LIVE 🎉
Body: [Exclusive cosmetic] is waiting. Event ends [date].
CTA: Tap to claim your first reward
```

```
Title: Halfway there! 
Body: You've earned [X] [currency]. [Y] more to unlock [exclusive item name].
CTA: Keep going →
```

### Last 24h Warning
```
Title: Final 24 hours — [Event Name]
Body: Don't miss [exclusive item]. It won't return.
CTA: Collect your rewards now
```
