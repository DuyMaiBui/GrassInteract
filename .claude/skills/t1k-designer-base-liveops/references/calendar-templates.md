# Live-Ops Calendar Templates

## Annual Event Calendar Blueprint

### Tier 1 — Major Events (5-7 days each, 4-6× per year)
Anchor to IRL moments. Full marketing cycle: press, influencer, UA bid spike.

| Month | Event Theme | Marketing Hook |
|-------|-------------|----------------|
| January | New Year / Lunar New Year | Cultural hook; CNY = massive Asia DAU spike |
| March/April | Spring / Anniversary | Game birthday = 2× DAU historically; press coverage |
| June/July | Summer | Content drop; back-to-school buying window |
| October/November | Halloween / Fall | Highest-engagement theme globally |
| December | Winter / Holiday | Highest monetization window of year; UA pause → retain mode |

### Tier 2 — Monthly Events (3-5 days each)
One per month, smaller scope. New mechanic or limited cosmetic. No full press cycle.

### Tier 3 — Weekly Challenges (7 days, every week)
Automated. Use existing systems. Meta-objective (win X matches, collect Y items).

---

## Weekly Schedule Template

| Day | Event Type | Content |
|-----|-----------|---------|
| Monday | Week start | New weekly challenge unlocks; weekly shop refreshes |
| Tuesday | — | Regular cadence |
| Wednesday | Mid-week surprise | Double drop on specific resource OR flash sale (24h) |
| Thursday | Community | Leaderboard snapshot shared on social (drives competition) |
| Friday | Weekend prep | New daily deal with weekend-themed item |
| Saturday | Peak DAU | Major event runs (Sat-Sun = highest active window) |
| Sunday | Retention | "Last chance" nudge for weekly challenge if incomplete |

---

## Monthly Event Arc Template (30-day season)

```
Week 1: Season launch → new content reveal + tutorial for new mechanics
Week 2: Mid-season challenge → harder objective, premium reward unlock
Week 3: Community event → cooperative milestone (all players contribute)
Week 4: Season finale → countdown + last-chance purchases + preview of next season
```

---

## Content Release Checklist

Before launching any live-ops event:
- [ ] Event duration ≥ 48h (coverage for all time zones)
- [ ] UA team briefed 4+ weeks in advance
- [ ] App store screenshots updated with event art
- [ ] Push notification copy approved (subject line, body, CTA)
- [ ] Influencer embargo assets sent 3 days before launch
- [ ] Reward balance reviewed (completion rate target: 40-70%)
- [ ] Event economy impact modeled (ARPDAU delta projection)
- [ ] Rollback plan defined (if event bugs cause economy exploit)
