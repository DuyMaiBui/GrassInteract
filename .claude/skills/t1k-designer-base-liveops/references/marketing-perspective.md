# Live-Ops Marketing Perspective

## UA Calendar Alignment

### 4-Week Pre-Launch Checklist
- **T-4 weeks**: Share event brief with UA team (event name, theme, duration, expected DAU spike %)
- **T-3 weeks**: UA team adjusts bid strategy (increase CPI budget 20-40% for event window)
- **T-2 weeks**: Creative team produces event-themed ad creatives (banner, video, playable)
- **T-1 week**: Influencer embargo assets delivered; press pitch sent
- **T-3 days**: Influencer early access window opens
- **T-1 day**: App store metadata updated (screenshots + promo text reflecting event)
- **Launch day**: Push notification + social post (all channels simultaneously)

### UA Bid Strategy During Events
- Events with strong D7/D30 → higher LTV → justify 30-50% higher CPI bids
- Allocate 60% of monthly UA budget to the 2-3 major event windows per year
- Post-event: D+3 retention analysis determines whether to extend event or retire

## App Store Featuring Playbook

Apple and Google featuring editorial teams look for:
1. **Active live content**: a live event running = "New Content" badge eligibility
2. **Seasonal relevance**: event themed to current season/holiday = higher chance of organic feature
3. **Screenshots updated**: event art in first 3 screenshots signals active development
4. **Rating spike**: events often drive review prompts → rating spikes → better featuring odds

### Actions Per Event
- Update first screenshot to feature event art on day of launch
- Submit for "New Content" featuring via App Store Connect / Google Play Console (feature request tool)
- Request review prompt within event flow (after rewarding moment, never during friction)

## Influencer / Creator Playbook

### Tier Selection
| Tier | Followers | Role | Activation |
|------|-----------|------|-----------|
| Nano | 1K-10K | Community seeding | Gift codes + early access |
| Micro | 10K-100K | Organic content | Early access + custom bundle |
| Mid-tier | 100K-1M | Primary reach | Early access + rev share or flat fee |
| Macro | 1M+ | Brand awareness | Paid deal; negotiate separately |

### Event Creator Brief Template
```
Event Name: [Name]
Access Window: [date] to [date] (3 days before public launch)
Content Angle: [1 unique hook — e.g., "first look at the new legendary skin drop"]
Deliverable: 1x TikTok/Reel/YouTube Short minimum, mention event launch date
Asset Pack: [link to drive with key art, gameplay clips, talking points]
Embargo: do not post before [date/time]
```

### TikTok-able Design Checklist
Each major event should have at least 1 "moment" that makes for shareable short-form content:
- [ ] Dramatic visual reveal (new boss, rare skin, map transformation)
- [ ] Countdown timer visible in-game UI (urgency = shareability)
- [ ] Surprise mechanic or easter egg discoverable by players
- [ ] Limited-edition cosmetic preview screen (players share their unboxing)

## Press Cycle

### Who to Pitch (Mobile Gaming Press)
- Pocket Gamer (global mobile games; highest domain authority for mobile)
- Touch Arcade (Apple ecosystem; iOS-first titles)
- Droid Gamers (Android)
- Game Developer (dev community; technical angle)

### Embargo Pitch Template
```
Subject: [Game Name] | [Event Name] — Embargo [Date]

Hi [editor],

[Game Name] is launching [Event Name] on [date]. Here's what's new:
- [3 bullet points: unique mechanic, visual hook, reward hook]

Assets available under embargo at: [link]
Happy to arrange early access code or dev interview.

[signature]
```

### Timing
- Pitch 7 days before event launch
- Lift embargo same day as event launch (ensures coverage appears simultaneously with player-facing content)
- Follow up with data note 72h post-launch: "Event drove X% DAU spike" (journalists love post-event data hooks)
