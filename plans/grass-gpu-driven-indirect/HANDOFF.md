## Key Decisions Made
- **Tiered architecture, coexist not replace** — GPU high tier + existing CPU low tier behind `IGrassEngine`; runtime probe selects.
- **Deform fully on GPU (vertex shader), stateless** — wind reconstructed from `posWS`, lean from a per-frame interactor `StructuredBuffer`. Consequence: GPU recovery is INSTANTANEOUS (no rate-limited return); `recoveryRate` applies to the CPU tier only. This is the locked design (brainstorm).
- **`hash` is generic random, NOT baked wind-phase** (SSOT — VS derives phase from posWS).
- **`LodCount` is a computed getter**, not a stored field.
- **Fully GPU-driven chunk cull** (Compute A pre-pass), 3-tier LOD (cross-quad→quad→billboard) — user choices in brainstorm.
- **Sequential execution, one agent per phase with approval gates** — user rejected full-parallel (data deps + single live Unity editor + git:false → no worktree isolation).

## Critical gotchas discovered (also in project memory `grassinteract-project-status`)
- **`new RenderParams { ... }` object-initializer leaves `renderingLayerMask=0` → URP SILENTLY SKIPS THE DRAW.** Use `new RenderParams(material)` ctor. (This cost the most debugging in P5.)
- **`shader_feature_local` keywords toggled only at runtime get STRIPPED from player builds** → use `multi_compile_local`. (LOD2 billboard would be silently dead on device.)
- **`UnityStats.triangles` does NOT count `RenderMeshIndirect`** instances — verify renders via SCREENSHOT (Unity's own Stats panel warns).
- **`TWO_PI`/`PI`/`HALF_PI` are predefined URP HLSL macros** — redefining `static const float TWO_PI` → "unexpected float constant". Use `GRASS_TWO_PI`.
- **Correct API name is `SystemInfo.supportsIndirectArgumentsBuffer`** (Arguments plural, Buffer singular) — NOT `supportsIndirectArgumentBuffers` (the plan's assumed name doesn't exist).
- Screenshot capture inflates that frame's CPU time (saw 287ms/1022ms during capture vs 7-9ms clean) — measure perf via `Time.smoothDeltaTime`, not the capture frame.
- Two live Unity instances historically — always `set_active_instance GrassInteract@de203215` (port 6403) + self-identify via `Application.dataPath`.
