## Key Decisions Made
- WorldPainter is the SOLE renderer; all legacy renderers deleted (0 class defs remain project-wide).
- One self-contained WorldMapAsset SO; **everything nested** incl. heavy tile bytes (accepted multi-MB/coarse-diff tradeoff).
- Editor SSOT = container; runtime = **bake step → one standalone TerrainTileAsset per tile + manifest** for streaming (resolves "whole asset loads at once" RAM problem).
- Map-level layer definition + **per-tile R8 256×256 density** channel (nested on each tile). Props = explicit TRS records **bucketed per-tile**.
- Tile creation is **in-current-scene** (factory + SceneView ghost quads, signed coords) — NO EditorSceneManager.NewScene.
- Tile-agnostic world-space brush (never select a tile); brush stamps are **editor-global Resources**, not map sub-assets.
- No migration tool — disposable data; fresh demo built via Unity MCP.
